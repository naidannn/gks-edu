# TASKS.md — Ажлын жагсаалт ба төлөв

`ROADMAP.md`-ийн үе шат бүрийг гүйцэтгэх боломжтой жижиг таск болгон задалсан.
**Энэ файл бол ажлын цорын ганц эх сурвалж** — таск эхлүүлэхэд `wip`, дуусахад `done` болгож
шинэчилнэ.

## Тэмдэглэгээ

| Төлөв | Утга |
|---|---|
| `todo` | Эхлээгүй |
| `wip` | Хийгдэж байна |
| `review` | Код бэлэн, хянагдаж байна |
| `done` | Дууссан, шалгагдсан, нэгтгэгдсэн |
| `blocked` | Бизнесийн шийдвэр/гадаад хамаарлаар зогссон (`ARCHITECTURE.md` §18-д асуултыг нэм) |
| `deferred` | Хойшлуулсан, энэ үе шатанд хийхгүй |

**Хэмжээ:** `S` ≤ 0.5 өдөр · `M` 1–2 өдөр · `L` 3–5 өдөр

**Явц харах:** `pnpm tasks`
