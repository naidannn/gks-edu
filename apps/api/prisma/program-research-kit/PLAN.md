# Анги · танхим · төлбөр · тэтгэлгийн судалгааны төлөвлөгөө (1I-10)

Элсэлтийн судалгаатай (1H-12, `../intake-research-kit/`) ижил зарчмаар: сургуулийн **өөрийн
албан ёсны** вэб/PDF-ээс уншина, сургууль тус бүрт нэг JSON файл бичнэ, өгөгдлийн санд зөвхөн
импорт скрипт бичнэ (`--dry`-аар эхлээд шалгана).

## 1. Зорилго

Нэг сургууль бүрийн хувьд гадаад (외국인) оюутанд нээлттэй:

| Юу | Системийн талбар | Хаанаас |
|---|---|---|
| Танхим (단과대학) | `Faculty.nameKo / nameEn / nameMn` | 외국인 모집요강-ийн 모집단위 хүснэгт |
| Анги (학과/전공) | `UniversityProgram` (`level`, `nameKo`, `nameEn`, `nameMn`, `facultyId`) | мөн тэр хүснэгт; магистр/докторт 대학원 모집요강-ийн 모집학과 |
| Сургалтын төлбөр | `tuitionPerTermKrw` (улирлаар), `tuitionYear`, `admissionFeeKrw` (입학금) | 등록금 안내 / 모집요강-ийн 등록금 хэсэг |
| Хэлний шаардлага | `topikLevel`, `ieltsScore`, `language` | 지원자격 |
| Тэтгэлэг | `scholarshipMaxPercent`, `scholarshipNote` | 외국인 장학금 안내 (입학/재학 장학) |
| Эх сурвалж | `sourceUrl`, `sourceType = AI_ASSISTED`, `verifiedAt = null` | |

Хэлний бэлтгэл (`LANGUAGE_PREP`) — нэг анги: "Солонгос хэлний бэлтгэл" (한국어교육원 정규과정),
улирлын төлбөр + 입학금 (= 1I-11-ийн асуулт мөн хариулагдана).

## 2. Солонгос сургуулиуд мэдээллээ хэрхэн нийтэлдэг вэ (судлах дараалал)

1. **Гадаад оюутны элсэлтийн журам (외국인 특별전형 모집요강)** — бакалаврын хувьд хамгийн
   найдвартай эх сурвалж: гадаад оюутан авдаг 모집단위 (танхим → анги) хүснэгт, 지원자격 (TOPIK),
   ихэнхдээ 등록금 болон 장학금 хэсэг бүгд нэг PDF-д байдаг. 1H-12-д уншсан PDF-ийн холбоос
   `../data/intake-research/<slug>.json`-ийн `sourceUrl`-д бий — тэндээс эхэлнэ.
2. **Магистр/доктор (일반대학원 외국인 모집요강)** — 모집학과 (석사/박사 тус тусдаа), 계열-ээр
   төлбөр. Мэргэжлийн/тусгай 대학원 (경영전문대학원 гэх мэт) энэ ээлжинд **орохгүй** — зөвхөн 일반대학원.
3. **Төлбөр (등록금)** — Солонгос сургуулиуд төлбөрийг ангиар биш **계열-ээр** (인문사회 / 자연과학 /
   공학 / 예체능 / 의학) нийтэлдэг. Тиймээс судалгаа эхлээд `tuitionTables` (계열 → улирлын
   төлбөр) бичнэ, анги бүр өөрийн `tuitionGroup`-ийг заана, импорт тоог тараана. Хэрэв сургууль
   ангиар нийтэлсэн бол ангид шууд бичнэ.
   - Улирлын дүнг хадгална, ×2 жилийн дүнг хэзээ ч бичихгүй.
   - `tuitionYear` = хүснэгтийн хичээлийн жил (2026 эсвэл 2027). Он заагаагүй хүснэгт → `null`
     бичихгүй, `pending`.
4. **Тэтгэлэг (외국인 장학금)** — ихэнх сургуульд сургуулийн хэмжээний дүрэм: элсэлтийн тэтгэлэг
   TOPIK-ийн түвшнээр (ж: TOPIK 4 → 30%, 5 → 50%, 6 → 100%), дараагийн улирлууд дүнгээр (GPA).
   - Судалгааны файлд бүтэцтэйгээр бичнэ (`scholarships[]`: түвшин, төрөл, нөхцөл, хувь).
   - Импорт ангийн `scholarshipMaxPercent`-д тухайн түвшинд **бодитоор авч болох** хамгийн өндөр
     элсэлтийн хувийг, `scholarshipNote`-д монгол товч тайлбарыг (ж: "TOPIK 5 бол эхний улирал
     50%, дараа нь голч 3.0+ бол 30%") бичнэ. GKS (засгийн газрын) тэтгэлэг энд **орохгүй**.
5. **Монголын иргэдэд зориулсан тусгай дүрэм** (өндөр TOPIK, нэмэлт санхүүгийн баталгаа,
   ярилцлага) — элсэлтийн судалгаатай адил `requirementNote`/тайлан руу.

## 3. Судалгааны файл

`apps/api/prisma/data/program-research/<slug>.json`:

```jsonc
{
  "slug": "…", "researchedAt": "YYYY-MM-DD",
  "tuitionTables": [
    { "level": "BACHELOR", "group": "공학", "tuitionPerTermKrw": 4780000,
      "admissionFeeKrw": 0, "tuitionYear": 2026, "sourceUrl": "…", "evidence": "…" }
  ],
  "faculties": [ { "nameKo": "공과대학", "nameEn": "College of Engineering", "nameMn": "Инженерийн танхим" } ],
  "programs": [
    { "level": "BACHELOR", "faculty": "공과대학", "nameKo": "컴퓨터공학과",
      "nameEn": "Computer Science and Engineering", "nameMn": "Компьютерийн инженерчлэл",
      "tuitionGroup": "공학", "durationYears": 4, "language": "KOREAN", "topikLevel": 3,
      "sourceUrl": "…", "confidence": "HIGH" }
  ],
  "scholarships": [
    { "levels": ["BACHELOR"], "kind": "ENTRANCE", "criteria": "TOPIK 5", "percent": 50,
      "noteMn": "…", "sourceUrl": "…", "evidence": "…" }
  ],
  "notOffered": ["PHD"],
  "pending": [ { "what": "…", "reason": "… (монголоор)", "checkAt": "…" } ]
}
```

Хатуу дүрэм (1H-12-ээс уламжилсан):
- `sourceUrl` зөвхөн сургуулийн албан ёсны домэйн (*.ac.kr, uwayapply/jinhakapply). Агентлаг,
  блог, StudyU — зөвхөн чиглүүлэгч, эх сурвалж биш.
- Таах, өмнөх жилийн тоог шилжүүлэх хориотой — `null` нь таамгаас дээр.
- `nameKo` нь сургуулийн бичсэнээр (1I-14: анги/танхимыг солонгос нэрээр нь таньдаг).
  `nameMn` — бидний орчуулга; нийтэд харагдана, тиймээс энгийн, ойлгомжтой монгол.
- `scholarshipNote` болон бусад нийтийн текст монгол, "AI", "эх сурвалж" гэх үг ороогүй.

## 4. Импорт (`pnpm programs:import`, `--dry`, `--only <slug>`)

- Түлхүүр: (сургууль, түвшин, `nameKo`) — 1I-14-ийн давхардлын индекс.
- Оффисын баталгаажуулсан (`verifiedAt`) мөрийг хөндөхгүй, зөрүүг зөвхөн тайлагнана.
- `sourceType = AI_ASSISTED`, `isPublished = true` (элсэлтийн судалгааны шийдвэртэй адил шууд
  нийтлэгдэнэ, admin дээр "AI судалсан" тэмдэгтэй).
- Танхимыг `nameKo`-оор олно/үүсгэнэ. Ажилтан монголоор нэрлэсэн танхимын нэрийг хөндөхгүй.
- Файлд байхгүй, баталгаажаагүй хуучин анги устгахгүй — зөвхөн тайлагнана.
- "Хэзээ судалсан" бичлэг (`IntakeResearchRecord` шиг) туршилтад **ороогүй** — схем өөрчлөх
  шаардлагатай; давалгаа эхлэхээс өмнө шийднэ.

## 5. Шилжилт: хуучин өгөгдлийг устгах

Хэрэглэгчийн шийдвэр (2026-10-08): production дээрх одоогийн анги/танхим/төлбөр/тэтгэлгийн
өгөгдлийг устгаад шинээр эхлэх. Устгахаас өмнө:
1. `prisma/purge-programs.ts` устгах мөр бүрийг `.backups/purge-programs-<огноо>/`-д JSON-оор
   нөөцөлнө (`--commit`-гүй бол зөвхөн тайлагнана).
2. Тоолж тайлагнана: хэрэг/мэдүүлэг/сонголт хэдэн ангид холбогдсон (`SetNull` болно),
   `intake_program_overrides` хэд (cascade-аар устна).
3. Нэг транзакцаар устгана, дараа нь GKS-ийн жагсаалтыг дахин тооцоолно.

## 7. Шийдвэрүүд (2026-10-08)

1. Туршилтын сургууль: **Korea University (고려대학교)**.
2. Устгах хүрээ: бакалавр/магистр/докторын анги ба **бүх танхим** устна. Оффисын хүснэгтээс

## 8. Туршилтаас сурсан зүйл (Korea University, 2026-10-08)

- **Гадаад оюутны төлбөр дотоодынхоос өөр байж болно.** Корёо их сургуулийн олон улсын хэлтэс
  бакалаврын төлбөрийг дотоодынхоос ~1.42 дахин өндөр ("Approx.") нийтэлдэг. Эх сурвалж нь
  гадаад оюутны хуудас байх ёстой; дотоодын 등록금 일람표-г зөвхөн ангиллын харьцуулалтад ашиглана.
- **Магистр/докторын төлбөр**: 일반대학원 등록금 일람표 PDF анги бүрийг 계열-д хуваарилдаг —
  хамгийн найдвартай эх сурвалж. Гадаад оюутны хуудасны тоо түүнтэй ижил байв.
- **Бакалаврт 입학금 байхгүй** (2023 оноос хуулиар хасагдсан) → `0`. Магистрт бий (1,142,000₩).
- **Анги жагсаалт JS-ээр ачаалагддаг** (graduate.korea.ac.kr): `fetch.sh` хоосон хуудас өгвөл
  хуудасны `$.post(...)` хаягийг олж шууд дуудна.
- **Тэтгэлэг ихэнхдээ элсэлтийн оноогоор**, TOPIK-ийн шатлалаар биш. Магистрын тэтгэлэг зөвхөн
  эхний улиралд → тэмдэглэлд заавал бичнэ. `headline` = энгийн сайн оюутан авах боломжтой хувь;
  100%-ийг цөөн шилдэгт өгдөг бол тэмдэглэлд дурдана, гарчигт биш.
- **Хасах зүйл**: 계약학과 (байгууллагын захиалгат), 특수/전문대학원, өөр кампус (тусдаа slug).
- Нэг сургууль ~60 tool call (Opus). 209 анги: бакалавр 63, магистр 73, доктор 73.
